How it works

OpenDocument files (.odt/.ods/.odp) are ZIP archives containing XML. When a file is corrupt, this tool tries three strategies in order:

  1. Standard ZIP read — opens the archive and validates each entry.
  2. Low-level scan — when the central directory is broken, scans the byte stream for ZIP local-file headers and reconstructs entries one by one.
  3. XML repair & text rescue — fixes truncated or malformed XML, then pulls paragraph and heading text from content.xml as a plain-text fallback.

The repaired document is rebuilt as a valid ODF package — the mimetype member is written first and uncompressed, exactly as the OpenDocument spec requires, so LibreOffice and OpenOffice recognise it.
